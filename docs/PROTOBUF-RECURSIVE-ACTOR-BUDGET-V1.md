# Candidate recursive Protobuf actor DATA preflight

This allocation-free Rust host reference walks only descriptor-declared embedded messages; byte/string-like fields remain opaque. One meter spans root and descendants, accounting for input retention, conservative per-message and field storage, payload copies, byte reads and schema lookup/validation work. Unknown fields, wrong wire types, groups and invalid descriptors fail closed. Repeated occurrences consume shared credit even when empty. No new language syntax; this does not yet implement typed materialization, packed scalars, field cardinality, UTF-8 semantics, unknown-field preservation, or schema authentication. The legacy descriptor-independent decoder is unchanged. A future guest decoder must charge actual materialization on the same meter rather than start a fresh allowance. Independent review required.
