# Restricted FlatBuffers host admission and shape identity

The scalar root table profile gains an explicit host-reference endpoint. Codec policy and generation precede wire reservation; bounded preflight precedes owned immutable snapshot; final publication rechecks generation. No borrowed view or production support enablement. Digest reference supports a single reachable table with 1..64 scalar fields (bool/i64/u32/f64), contiguous slots, named nodes and sorted canonical bytes. Registration still accepts a trusted supplied digest (like CBOR/Protobuf reference); deriving the digest directly from a compiler descriptor is not implemented here. FlatBuffers default omissions, recursive tables, pointers and other layouts remain unsupported. Tests verify wrong metadata, malformed scalar, copied storage, credit restoration and stale generation. This is not actual authenticated transport or compiler guest.

Reconciled endpoint now carries exact planned work and aggregate expansion credit through receiver materialization and fenced synchronous or suspended dispatch. The cumulative endpoint budget includes both passes and the wire copy, not just a single decoder pass. See ACTOR-DATA-PINNED-INGRESS-V1.md. This is still a host reference only.
