# Serialization host reference microbenchmark

Identical logical record (paid=true,total=-42,count=4294967295), independent flatc binary, CBOR signed i64 count and Protobuf raw fixed-width fields. Each implementation must decode the expected values before timing. Rust optimized release binary, black_box inputs/results, 10,000 warm-up operations per phase, seven measured batches. Report median/min/max batch-normalized ns/op, median ops/s and wire MiB/s; not per-request latency percentiles. Separate preflight, owned decode and combined two-pass timings. No network, authentication, scheduler, physical allocation counts or guest compiler. Different wire representations, metering and host value shapes mean this is a reference baseline, not a fair production codec ranking or Atto-vs-Rust target. Record runner CPU/toolchain and fixture hash with measurements. No hard timing gate on shared CI.
