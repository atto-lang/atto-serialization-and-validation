# Candidate FlatBuffers scalar table profile

Based on https://flatbuffers.dev/internals/ : little-endian root uoffset, signed backward vtable offset, vtable byte/object lengths and field offsets. This deliberately restricted profile accepts one root table with all registered scalar fields present, nonoverlapping aligned fields, exact object extent, zero padding, and a backward nonshared vtable. Limits: 4096 wire bytes, 64 fields; bounded fixed scratch; shared preflight/materialization parser; conservative logical and work charges before allocation. Refuse absent fields/defaults, pointers, nested objects, vectors, aliases, size prefix, identifiers, nonfinite floats and any unsupported layout. Owned values only, no zero-copy, compiler descriptor, nominal ADT, or runtime authority claim. Official flatc fixture is required in CI as an independent positive interoperability check; the standalone test reports when absent. No support-mask enablement or IPC registration yet.
