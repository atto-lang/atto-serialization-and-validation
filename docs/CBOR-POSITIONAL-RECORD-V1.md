# Candidate actor DATA CBOR positional records

Records use a definite-length CBOR array in trusted registration-time schema order. Exact arity and per-field shape are required. A record is not an arbitrary map and cannot infer its nominal type from the payload. A homogeneous list and record may have identical wire bytes; only authenticated descriptor selection may distinguish them. Existing wire profile, shortest lengths, finite binary64, depth and cumulative logical resource budgets remain unchanged. Decode reserves only after minimum child work/depth/expanded checks; encoder measures before allocating. This is an opt-in Rust host model, not a published cross-backend schema policy or guest proof. The caller must bind nominal schema identity, field order and version to authenticated ingress; no field reordering or implicit defaults are allowed. Three new regression groups cover exact budgets, shape/canonical rejection and nesting.
