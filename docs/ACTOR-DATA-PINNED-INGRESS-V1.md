# Pinned actor DATA ingress host reference

Compose fixed registration-time codec, nominal schema, version, shape digest and receiver generation with allocation-free typed preflight and a generation-fenced mailbox reservation. Only a trusted transport may call the post-authentication entrypoint using exact authenticated metadata and immutable payload. This module does NOT authenticate peers, verify a MAC, derive the descriptor digest, enforce replay protection or bind endpoint identity cryptographically. Those remain external prerequisites; synthetic metadata in tests is not authentication evidence. The caller must bound ingress snapshot storage and account receiver materialization separately; no decoded values are published by this reference. CBOR preflight and Protobuf preflight use their existing independent logical limits; no fresh decoding budget is implicitly authorized. Mailbox tenant credit covers owned wire bytes and follows delivery. No CONTROL authority or compiler guest claim.
